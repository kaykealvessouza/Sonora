# Sonora 🎵

Projeto desenvolvido para a disciplina de **Programação Orientada a Objetos (POO)** da **Universidade Regional de Blumenau (FURB)**.

O **Sonora** é um sistema de streaming desenvolvido de forma incremental ao longo das atividades da disciplina. O projeto acompanha a evolução dos conceitos de Programação Orientada a Objetos, começando com classes e encapsulamento e avançando para exceções, testes automatizados, coleções, associações, herança, abstração e outros conceitos.

## Sobre o projeto

O Sonora simula uma plataforma de streaming capaz de trabalhar com usuários, músicas, playlists e diferentes tipos de conteúdo.

Ao longo das etapas, o projeto é continuamente expandido e refatorado para aplicar novos conceitos de POO sem perder as funcionalidades desenvolvidas anteriormente.

A ideia é que cada etapa represente uma evolução do mesmo sistema, permitindo acompanhar na prática como diferentes conceitos de orientação a objetos podem ser aplicados em um projeto maior.

## Evolução do projeto

O Sonora é desenvolvido de forma incremental. A cada nova etapa da disciplina, novas funcionalidades e conceitos de Programação Orientada a Objetos são incorporados ao projeto.

A documentação detalhada de cada etapa está disponível separadamente na pasta:

```text
README/
```

Dentro dela existe um README correspondente a cada etapa desenvolvida, contendo os objetivos, conceitos trabalhados, alterações realizadas e demais informações específicas daquela fase.

Dessa forma, o README principal apresenta o projeto de maneira geral, enquanto os arquivos individuais registram sua evolução ao longo do desenvolvimento.

## Testes

Os testes automatizados ficam na pasta:

```text
test/main/
```

O projeto utiliza o JUnit através do arquivo:

```text
lib/junit-platform-console-standalone-6.0.0.jar
```

Os testes podem ser executados utilizando o JUnit Console Launcher.
